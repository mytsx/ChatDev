# Developer Guidelines

## Scope Rules
- ONLY create/modify files listed in your assigned task's "Files" section
- NEVER refactor, optimize, or "improve" code outside your task scope
- NEVER add features not specified in the architecture document
- When existing code exists, follow its conventions

## Code Quality Standards
- Max function length: 50 lines
- Max parameters: 5 (use config object if more)
- Max nesting: 3 levels
- No TODO/FIXME placeholders — write complete implementations

## Research-Before-Code
Before using ANY library/framework:
1. Verify correct API usage via Context7
2. Check for deprecated APIs
3. Read migration guides for breaking changes

## Output Requirements
Your response MUST include:
1. List of all files created/modified with paths
2. No TODO or FIXME placeholders in code
3. All error handling implemented, not stubbed
